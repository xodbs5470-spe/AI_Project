# 저금이돈 - AI 기반 맞춤형 지출 관리 & 절약 코칭 서비스

> **목표 달성을 위한 스마트한 소비 가이드!**  
> AI가 일일 지출 한도를 계산해주고, 지출 내역을 분석하여 리밸런싱해주는 개인 맞춤형 가계부 서비스입니다.

---

# 주요 기능 (Key Features)

1. **AI 맞춤형 일일 지출 한도 설정**
   - 목표 금액과 남은 기간에 맞춰 오늘의 권장 점심값 및 일일 지출 한도 제안
2. **소비 내역 AI 분석 & 피드백**
   - 하루 지출 내역을 기반으로 소비 평점 부여 및 낭비 요인 개선 피드백 제공
3. **돌발 지출 위기 관리 (리밸런싱)**
   - 예상치 못한 갑작스러운 지출 발생 시 남은 기간의 일별 예산 자동 재산출

---

# 기술 스택 (Tech Stack)

- **Frontend**: React / HTML5 / CSS3 / JavaScript
- **Backend**: Node.js (Express) or Python (FastAPI)
- **Database**: PostgreSQL / MySQL
- **AI API**: OpenAI GPT-4o API / Google Gemini API
